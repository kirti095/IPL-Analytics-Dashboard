# 🏏 IPL Analytics Dashboard | Python + SQL + React

An interactive **IPL Cricket Analytics Dashboard** designed to transform IPL match and player data into meaningful insights through **data analysis, visualization, predictive analytics, and modern dashboard development**.

The project analyzes **player performance, team statistics, venue records, toss impact, season-wise trends, and match-winning patterns** through an interactive and responsive dashboard.

---

## 📌 Project Overview

The IPL generates a large volume of match, player, team, and venue data every season.

This project uses data analytics techniques to transform that data into actionable cricket insights and provide users with an easy-to-explore analytical dashboard.

The platform combines a **Python-based analytics workflow** with a **React.js frontend** to create an interactive sports analytics experience.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Python 3.x
* Node.js
* npm
* SQL database (if applicable)

---

### 1. Clone the Repository

```bash id="6t8xq3"
git clone https://github.com/kirti095/IPL-Analytics-Dashboard.git
```

### 2. Navigate to the Project

```bash id="q7h4km"
cd IPL-Analytics-Dashboard
```

### 3. Install Python Dependencies

```bash id="1z9r8p"
pip install pandas numpy matplotlib seaborn
```

### 4. Install Frontend Dependencies

```bash id="8w2x7n"
npm install
```

### 5. Start the Dashboard

```bash id="v5c9qx"
npm run dev
```

The application will then be available through the local development URL provided by your React/Vite setup.
